# Clínica Fisio — Conciliação, Comissionamento e Agenda

App (v1) que substitui o ZenFisio por completo: agenda dos fisioterapeutas, check-in/confirmação de atendimento via QR code, cadastro de modalidades de pagamento, e cálculo automático do repasse de cada profissional. Roda numa VPS própria (Hostinger + Coolify).

- **Brief de negócio (ponto de partida):** [`docs/superpowers/specs/2026-08-29-conciliacao-comissionamento-design.md`](docs/superpowers/specs/2026-08-29-conciliacao-comissionamento-design.md)
- **Setup do ambiente (VPS Hostinger + Coolify + code-server):** [`docs/setup-vps-clinica.md`](docs/setup-vps-clinica.md)

Este projeto ainda não tem stack técnica definida — decisão fica para a sessão do Claude Code rodando na VPS da clínica, junto com o Bruno.
